# Building with agents

An honest log of building this project with an agent as tutor and researcher: what I asked for, where the agent was wrong, and what I caught.

Format: `YYYY-MM-DD — what I asked for — what happened — what I caught or changed (link to diff)`

## Log

- 2026-09-28 — Delegated the "Before starting" research (Bedrock models, S3 Vectors/Comprehend regions, name clashes) — agent found all three name candidates taken on PyPI, Haiku 4.5 not in GovCloud, Comprehend PII in us-gov-west-1 only; the agent defaulted to Claude-specific framing and suggested a local Jenkins demo — I refocused on CI/CD with a swappable model behind a provider layer, dropped Jenkins, and kept Haiku 4.5 over DeepSeek.
- 2026-09-28 — Delegated AWS account setup checks for the new Sanitas account — agent turned a comment about who owns the org's root into an unrequested lecture on employment-agreement IP risk and suggested moving to a personal account — I shut it down: this is company-approved R&D and the only real constraint is spend. Redirected the caution into the budget alarm.
- 2026-09-29 — Branch protection lesson — agent had me edit the tutorial log on the PR branch, then told me to `git switch main`, which Git refused because it would overwrite uncommitted changes; it also gave a slightly wrong UI path ("New ruleset" is a dropdown) — committed the log first, then did the probe. Gate verified: direct push rejected, PR blocked until green.
- 2026-09-29 — CI image build + test lesson — agent predicted the uncached build would be slow and planned a layer cache; measured 28 s total, so I skipped the cache. It again gave a wrong ruleset UI path (Settings → Rules → Rulesets → `main`); I only saw "New ruleset" and pushed back — it switched to the direct `/settings/rules/<id>` URL. Gate verified: red PR went `UNSTABLE` → `BLOCKED`.
- 2026-09-29 — Ruff lint lesson — agent said ruff's default rules were minimal and import sorting would be an opt-in later; the red/green run failed with `I001` too, because ruff 0.16 enables it by default. The agent also missed that PR #7 hadn't merged before I branched; it caught that when `main` lacked `docker.yml`. A container-vs-laptop file count difference showed `.gitignore`d `CLAUDE.local.md` inside local images; `.dockerignore` fixed.
- 2026-09-29 — Labeled data lesson — agent picked ai4privacy `openpii-masking-mini-10k` after checking licenses (CC-BY-4.0, not gated; other sets are custom or gated commercial). The sampling script it gave me failed ruff (FURB122, line too long); it caught that by running the CI lint locally before I pushed. It also flagged that the synthetic data is mostly non-US formats, so Presidio's US recognizers will score low on some labels for format reasons.
- 2026-09-29 — Scoring harness lesson — asked the agent to write the Python directly (the app is a vehicle for CI/CD, not the point). It kept over-explaining metric tradeoffs (F1 vs F2, ratchets, label coverage) until I told it twice this is a DevOps learning project; it saved that to memory. Eval gate added to the `test` job; CI reproduced the laptop numbers exactly.
- 2026-09-29 — OIDC lesson start — agent told me to `aws login --profile sanitas`, then `--profile tf`; both are chained profiles (assume-role and credential_process) and only `default` holds the login session. Took four tries plus finding `AWS_PROFILE=tf` in my shell. Also: I had to ask twice what OIDC is *for* before the agent explained it in terms of what GitHub actually needs to do in AWS.
